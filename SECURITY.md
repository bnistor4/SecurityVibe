# Security Policy

## About this repository

SecurityVibe is a **defensive documentation and testing toolkit**. It does not contain exploit code.

## Reporting vulnerabilities in SecurityVibe itself

If you find an issue in this repository (incorrect guidance, accidental secret, etc.):

1. Open a [documentation gap issue](.github/ISSUE_TEMPLATE/documentation-gap.md) for non-sensitive corrections.
2. For sensitive matters, contact the repository maintainer privately if a security contact is listed in the GitHub org/profile.

## Using SecurityVibe on your projects

You must have **explicit authorization** before running audits, scripts, or tests against any system you do not own or operate.

Do not use this toolkit to attack third-party services without permission.

## Scope boundary

Contributions that add payloads, PoCs, or weaponization instructions will be rejected.
